# ⚖️ Calculador-IMC

**Autor:** Miguel Assis

## Sobre
Calculadora de Índice de Massa Corporal (IMC) totalmente funcional, que recebe peso e altura do usuário e retorna o resultado do cálculo com sua respectiva classificação.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Estrutura
- `index.html` — estrutura da página
- `style.css` — estilização
- `script.js` — lógica de cálculo do IMC
